Why Flutter?

Flutter lets you ship one codebase to iOS, Android, and the web. For portfolio and product work, hot reload and a rich widget catalog keep iteration fast without sacrificing native feel.

Setup

Install the Flutter SDK, run flutter doctor, and create a project with flutter create my_app. Use VS Code or Android Studio with the Flutter extension for the best debugging experience.

Your first widget

Everything in Flutter is a widget. Start with MaterialApp and Scaffold, then build a simple Column with Text and a ElevatedButton.

Next steps

  • Learn layout: Row, Column, Expanded, and constraints
  • Add navigation with go_router
  • Connect to APIs with http or dio
  • Test on a real device early — emulators hide performance issues
